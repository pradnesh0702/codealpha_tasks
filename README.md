## 🔍 Task 1: Basic Network Sniffer

### Overview

Developed a network packet analysis tool using Python to capture and dissect real-time network traffic. This project focuses on understanding data flow dynamics, packet structures, and fundamental networking protocols.

### Key Features & Objectives Covered

* **Packet Capture:** Built using libraries like `scapy` or `socket` to sniff live network traffic.
* **Protocol Dissection:** Analyzed captured packets to map out structural components and data payload details.
* **Key Metrics Extracted:** Displays essential packet headers, including:
* Source and Destination IP addresses.
* Transport/Network Protocols.
* Raw packet payloads for analytical inspection.

## 🎣 Task 2: Phishing Awareness Training

### Overview

Created a comprehensive educational presentation/online training module designed to mitigate human-centric security risks. The module is focused on identifying social engineering tactics and empowering users to defend against email and web-based phishing vectors.

### Key Features & Objectives Covered

* **Threat Identification:** Detailed methods to recognize sophisticated phishing emails and spoofed/fake websites.
* **Psychological Triggers:** Educated users on the common social engineering tactics used by malicious actors to manipulate behavior.
* **Defense & Mitigation:** Provided actionable best practices and vital security tips to avoid falling victim.
* **Engagement:** Integrated real-world phishing examples and interactive quiz segments to reinforce learned behaviors.

## 🛡️ Task 3: Secure Coding Review

### Overview

Conducted a rigorous security audit and code review on a selected target application. The goal was to identify critical vulnerabilities, understand flawed patterns, and suggest hardened remediation practices.

### Key Features & Objectives Covered

* **Vulnerability Assessment:** Conducted automated and manual code audits to uncover potential software vulnerabilities (e.g., OWASP Top 10 risks).
* **Methodology:** Combined **static analyzers** with careful **manual code inspection** for maximum coverage.
* **Remediation & Best Practices:** Documented clear recommendations and best practices for writing secure code.
* **Reporting:** Provided a detailed findings report alongside actionable, concrete remediation steps to secure the codebase.
